# Места: наполнение карточек — инструкция для задачи по расписанию

## Зачем
В разделе «Места» (nomerok.ge/ru/places) тысячи организаций из открытых карт, но у большинства только название и точка на карте. Человек открывает карточку клиники — а там пусто. Задача: за запуск сделать 15–25 карточек полезными: чем занимается место, услуги, часы, телефоны, сайт и соцсети.

## Где взять список
Открой через WebFetch: `https://nomerok.ge/api/places-todo?city=batumi&n=25` (попроси вернуть JSON целиком, без сокращений). Там места без описания, сначала самые нужные разделы (медицина, госуслуги, образование, банки…). Поля: id, name, name_en, name_ka, cat, sub, addr, addr_ru, phones, site, ig.
Если адрес недоступен — `https://nomerok.ge/api/places-todo?city=batumi&cat=health&n=25`. Если и так нет — закончи и напиши, что список недоступен.

## Как искать
1. Если есть `site` — открой его (WebFetch): главная, «О нас», «Услуги», «Контакты».
2. Иначе WebSearch: «<name> Batumi», «<name_ka>», «<name> ბათუმი». Подходят: официальный сайт, страницы организации в Facebook и Instagram, справочники (yell.ge, 2gis, tbilisi.travel и т. п.), сайты министерств и больничных касс.
3. Убедись, что нашёл именно это место: совпадает город и адрес или телефон. Сомневаешься — не пиши.

## Что записать (одна строка CSV на место)
Шапка (ровно такая): `id,work_status,name_ru,addr_ru,phones,site,instagram,facebook,other_links,hours,desc_ru,desc_en,tags,sources,checked`
- `id` — из списка, без изменений.
- `work_status` — `работает` (есть свежие признаки: сайт живой, посты в 2025–2026), `закрыто` (прямо написано, что закрыто или переехало) или пусто, если неясно.
- `name_ru` — русское название, если у места его нет и оно естественно (например, «Республиканская клиническая больница»). Бренды латиницей не переводи — оставь пусто.
- `addr_ru` — адрес по-русски, если его нет: «Батуми, ул. Зураба Горгиладзе, 96».
- `phones` — через `;`, в формате +995…; только номера с официальных страниц самого места.
- `site`, `instagram`, `facebook`, `other_links` (через `;`) — только официальные страницы этого места.
- `hours` — как на сайте: «Пн–Пт 9:00–18:00; Сб 10:00–15:00».
- `desc_ru` — 300–700 знаков, своими словами, живо и по делу. Что это за место и что там можно сделать: направления врачей и услуги (списком через запятую), для кого, на каких языках говорят (если указано), особенности (круглосуточно, выезд на дом, детское отделение, парковка). Без «лучший», «ведущий», «качественный», без оценок, отзывов и цен, если их нет на официальной странице. Без выдумок: если про место почти ничего не известно — короткое описание из 1–2 фактов, не растягивай.
- `desc_en` — то же коротко по-английски (150–400 знаков).
- `tags` — 3–8 коротких меток через `;` в нижнем регистре: «узи», «педиатр», «стоматолог», «анализы», «круглосуточно», «русский язык».
- `sources` — ссылки, где взяты факты, через `;`.
- `checked` — сегодняшняя дата ГГГГ-ММ-ДД.

Если ничего достоверного не нашёл — всё равно добавь строку: `id`, пустые поля и `checked` (место больше не попадёт в список). Ничего не придумывай.

## Нельзя
- Копировать тексты дословно, переносить чужие отзывы и рейтинги.
- Брать фото (фото не добавляем).
- Медицинские обещания («вылечим», «гарантия»). Политика, скандалы, происшествия.
- Личные телефоны врачей и сотрудников — только номера организации.

## Сохранение
1. Репозиторий ekaiv2025-a11y/nomerok, `git pull --rebase`.
2. Добавь в `data/places-enrich.json` в массив `batches` объект `{ "id": "<ГГГГ-ММ-ДД-ЧЧ>", "csv": "<весь CSV одной строкой с \n между строками>" }`. CSV — с кавычками вокруг полей, где есть запятые или кавычки. Пачки старше 30 дней удали из файла (они уже применены).
3. `node scripts/check-places-enrich.mjs` — исправь ошибки.
4. Коммит `data/places-enrich.json`, пуш в main с повтором при ошибке сети: `for i in 1 2 3 4; do git push -q origin main && break; git pull -q --rebase origin main; sleep $((2**i)); done`.
Сайт применит пачку при ближайшей ежедневной проверке (около 11:00 по Тбилиси).

## В конце
Коротко: сколько мест обработано, у скольких есть описание, сколько не нашёл, сколько закрытых.
