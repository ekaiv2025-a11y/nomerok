# «Новостройки Грузии» — инструкция для задачи по расписанию

Раздел сайта: `/ru/novostroyki`. Данные: `data/projects.json`, тип записи в `lib/projects.ts`, проверка: `node scripts/check-projects.mjs`.
Общие правила (без политики, только факты, своими словами, коммит с повтором) — в `scripts/news-bot.md`.

## Зачем
Люди ищут в Google «ЖК <название>», «новостройки Батуми у моря», «новостройки Тбилиси цены». Каждая страница ЖК честно и подробно отвечает: кто строит, где, когда сдача, сколько стоит, что рядом. Внизу страницы есть форма заявки: человек оставляет контакт, NomerOk передаёт его партнёрскому агентству недвижимости.

## За один запуск
1. **2 новых ЖК.** Город по дню недели: пн, ср, пт — Батуми и Аджария (Батуми, Гонио, Кобулети, Махинджаури); вт, чт, сб — Тбилиси; вс — другие города (Кутаиси, Бакуриани, Гудаури, Рустави, Боржоми).
2. **Обновление.** Проверь самые старые по `updated` записи (1–2 ЖК): статус, срок сдачи, цену. Изменилось — поправь и обнови `updated`. Ничего не изменилось — просто обнови `updated`.
3. **Новости строительства (если есть свежее).** Старт продаж, новый проект, сдача дома, закладка, новые правила для застройщиков, крупные анонсы за последнюю неделю. 0–2 заметки в `lib/news/auto.json` с `rubric: "build"` (формат и правила — в news-bot.md, минимум 120 слов, источники). Без скандалов, судов и политики. Повторы с уже опубликованным не нужны.

## Как выбирать ЖК
- Списки комплексов по городу: korter.ge (каталог новостроек), сайты застройщиков, новости о старте продаж (bm.ge, forbes.ge, commersant.ge, interpressnews, batumelebi, newsgeorgia).
- Бери **строящиеся и недавно сданные** (с 2024 года) жилые комплексы, о которых есть данные хотя бы в 2 независимых источниках. Сначала крупные и известные (их чаще ищут), потом остальные.
- Пропускай ЖК, которые уже есть в `data/projects.json`. Ищи по названию и по застройщику.
- Пропускай проекты, которые застройщик заморозил или бросил, если об этом есть новости. Исключение: если о проекте много спрашивают. Тогда опиши честно, со ссылкой на новость. Без оценок.

## Что можно брать и что нельзя
- **Можно:** факты своими словами — название, застройщик, адрес и район, этажность, число квартир, срок сдачи, статус, цена «от» за м² или за квартиру, отделка (белый, чёрный каркас, с ремонтом), инфраструктура комплекса, что рядом (море, парк, метро, школа), рассрочка, если её указывает сам застройщик.
- **Нельзя:** копировать тексты описаний, отзывы, фото и рендеры застройщика или korter.ge. Нельзя выдумывать цифры. Нельзя писать «лучший», «надёжный», «гарантированный доход», «выгоднее всех», «проверенный застройщик». Не обещай доходность от аренды.
- **Цена:** только из источника, с месяцем: `"price": { "perM2": 1100, "date": "ноябрь 2026", "src": "https://…" }`. Нет цены в открытых источниках — не пиши поле `price`, а в тексте напиши: «цены — по запросу у застройщика или по заявке».
- **Координаты:** из OpenStreetMap или из карты на сайте застройщика. Не уверен — не ставь.
- **Фото:** только `photo.q` для Wikimedia Commons — вид района или улицы, по-английски («Batumi New Boulevard skyline», «Saburtalo Tbilisi buildings»). `photo.alt` — что на фото («Новый бульвар Батуми»).

## Структура записи
```json
{
  "slug": "zhk-<name>-<city>",
  "name": "Название без «ЖК»",
  "city": "batumi",
  "district": "Новый бульвар",
  "address": "ул. Шерифа Химшиашвили, 7",
  "coords": [41.63, 41.61],
  "developer": "Застройщик",
  "developerUrl": "https://…",
  "status": "building",
  "completion": "IV квартал 2027",
  "price": { "perM2": 1100, "date": "ноябрь 2026", "src": "https://…" },
  "floors": "32",
  "units": 640,
  "features": ["300 м до моря", "бассейн", "белый каркас"],
  "lead": "2–3 предложения: что за комплекс, где, когда сдача.",
  "body": [
    { "h2": "О комплексе" }, { "p": "…" },
    { "h2": "Расположение и что рядом" }, { "p": "…" }, { "list": ["…"] },
    { "h2": "Квартиры и отделка" }, { "p": "…" },
    { "h2": "Цены и условия покупки" }, { "p": "…" },
    { "h2": "Застройщик" }, { "p": "Какие ещё проекты построил и сдал (факты)." },
    { "tip": "На что смотреть при покупке в этом районе: …" }
  ],
  "faq": [{ "q": "Когда сдача ЖК …?", "a": "…" }],
  "sources": [{ "name": "Сайт застройщика", "url": "https://…" }, { "name": "korter.ge", "url": "https://…" }],
  "photo": { "q": "Batumi New Boulevard skyline", "alt": "Новый бульвар Батуми" },
  "added": "2026-11-01",
  "updated": "2026-11-01"
}
```
- `status`: `presale` (старт продаж, стройка ещё не началась или котлован), `building` (строится), `done` (сдан).
- 400–900 слов, живым простым языком, без рекламы. Короткие абзацы.
- 3–6 `faq` в том виде, как ищут: «Когда сдача ЖК …», «Сколько стоит квартира в ЖК …», «Кто застройщик ЖК …», «Есть ли рассрочка в ЖК …».
- Ссылки на наши страницы можно ставить прямо в тексте: `[путеводитель по Батуми](/ru/georgia/batumi)`, `[как купить квартиру в Грузии](/ru/guide/<slug>)`. Ставь только существующие.
- Блок `cta` — не обязателен. Если ставишь, то про приёмку квартиры: `{ "cta": "Нужна приёмка квартиры или ремонт — специалисты", "cat": "inspection" }` или `repair`.
- Новые записи добавляй в начало массива.

## Проверка и публикация
1. `node scripts/check-projects.mjs`. Если добавлял новости — ещё `node scripts/check-news.mjs`. Потом `npx tsc --noEmit -p .` (если нет node_modules, сначала `npm ci`). Исправь ошибки.
2. Закоммить `data/projects.json` (и `lib/news/auto.json`, если менял) и запушь в main с повтором при ошибке сети, как в news-bot.md.
3. В конце коротко по-русски: какие ЖК добавлены (город, застройщик, откуда цена), что обновлено, какие новости строительства опубликованы.
