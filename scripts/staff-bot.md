# Врачи клиник — инструкция для задачи по расписанию

## Зачем
Решение владельца (06.11.2026): каталог наполняем сами. Врачи сами на сайт не регистрируются, а клиники публикуют свой персонал открыто. Мы делаем анкету каждого врача: должность, специализация, образование, опыт, языки, фото — и связываем её с клиникой. Записываются к врачу **только через телефон клиники**. Личных номеров врачей не берём никогда.

## Порядок за запуск
1. Репозиторий ekaiv2025-a11y/nomerok (если нет — add_repo с access: push, клонировать), `git pull --rebase`.
2. Выбери клинику:
   - сначала из списка «Очередь клиник» внизу — первую без `[x]`;
   - если очередь пуста — найди новую: открой WebFetch `https://nomerok.ge/api/place-find?cat=health&city=batumi&withSite=1` и выбери клинику с сайтом, у которой есть страница персонала («Врачи», «Наши специалисты», «Our team», «ექიმები»). Допиши её в очередь.
3. Найди клинику у нас. **Важно:** `/api/*` на nomerok.ge закрыт в robots.txt (`Disallow: /api`), поэтому WebFetch `https://nomerok.ge/api/place-find?...` всегда вернёт `robots_disallowed` — это не временный сбой, повторять не нужно. Правило сессии запрещает обходить отказ WebFetch (curl/bash и т.п.), поэтому ищи место локально в репозитории:
   - открой `data/places-batumi.json` (это и есть исходник таблицы `places`, `id` оттуда используется как есть) и найди запись(и), где `site` содержит домен клиники (`status: "published"`, не `hidden`/`dup_of`); если несколько филиалов — у каждого свой `id` и `addr_ru`;
   - проверь, что место реально есть на сайте: открой WebFetch его публичную страницу `https://nomerok.ge/ru/places/<slug>` (не /api — её отдаёт robots.txt `Allow: /`) и сверь название/адрес/телефон с тем, что на сайте клиники;
   - если нашёл и подтвердил — используй этот `id` как `place_id`;
   - если клиники в `data/places-batumi.json` нет (или не нашёл подтверждения) — вместо `place_id` добавь в пачку `"clinic": { "name", "site", "phones": [телефоны регистратуры с сайта], "addr_ru": "Батуми, ул. …", "hours", "desc_ru": "2–3 предложения о клинике по её сайту", "lat", "lng" (если есть на сайте/карте) }` — сайт сам найдёт клинику по домену сайта или создаст её карточку в «Местах» (см. `ensureClinic` в `lib/staff-import.ts`).
4. Открой страницу персонала и страницы врачей (WebFetch). За запуск — до 40 врачей. Если врачей больше — продолжишь в следующий запуск (в очереди допиши, на ком остановился).
5. Для каждого врача заполни (только то, что написано на сайте клиники, своими словами, без выдумок):
   - `name` — имя и фамилия по-русски, как на русской версии сайта; если её нет — транслитом с грузинского/английского;
   - `category` — `doctor`; стоматолог — `dentist`; психолог/психотерапевт — `psychologist`; логопед — `speech`; массажист/реабилитолог — `massage`;
   - `title` — должность и специальность как на сайте: «Кардиолог, эхокардиолог»;
   - `services` — что делает, коротко списком через перевод строки (консультации, процедуры, исследования), если указано;
   - `about` — 2–4 предложения о враче по фактам с сайта: специализация, опыт, с какими проблемами обращаться. Без «лучший», «ведущий», «высококвалифицированный», без обещаний вылечить;
   - `credentials` — образование, учёная степень, стажировки, членство в ассоциациях — если указаны;
   - `experience_years` — число, только если на сайте прямо указан стаж или год начала работы; иначе `null`;
   - `languages` — коды `ka`, `ru`, `en`, `tr`… только если указаны;
   - `photo` — прямая ссылка https на фото врача с сайта клиники (портрет), если есть; иначе `null`;
   - `source_url` — ссылка на страницу врача (или на страницу персонала, если отдельных страниц нет — тогда добавь `#имя-латиницей`, чтобы ссылка была уникальной);
   - `place_id` — только если врач работает в другом филиале, чем указан в пачке.
   Руководителей без приёма (директор, бухгалтер, администратор) и медсестёр не добавляй — только врачей и специалистов, к которым записываются пациенты.
6. Добавь в `data/staff-import.json` в `batches` объект:
   `{ "id": "<домен>-<ГГГГ-ММ-ДД>", "place_id": "<id клиники>", "staff": [ ... ] }` (или `"clinic": {…}` вместо `place_id`).
   Пачки старше 30 дней удали (они уже применены).
7. `node scripts/check-staff-import.mjs` — исправь ошибки.
8. Обнови очередь ниже (`[x]`, сколько врачей, где остановился), коммит `data/staff-import.json` и `scripts/staff-bot.md`, пуш в main с повтором:
   `for i in 1 2 3 4; do git push -q origin main && break; git pull -q --rebase origin main; sleep $((2**i)); done`
Сайт создаст анкеты при ближайшей ежедневной проверке (около 11:00 по Тбилиси), по 30 за раз.

## Нельзя
- Личные телефоны, Telegram, WhatsApp, почта врачей — только контакты клиники (их сайт возьмёт сам из карточки клиники).
- Отзывы, рейтинги, цены, которых нет на сайте клиники.
- Выдумывать опыт, образование, языки.
- Политика, скандалы, жалобы.

## В конце
Коротко: какая клиника, сколько врачей добавлено, сколько с фото, что осталось.
