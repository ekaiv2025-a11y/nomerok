# Афиша городов — инструкция для задачи по расписанию

## Зачем
Раздел nomerok.ge/ru/afisha — события по городам Грузии на ближайшие недели. Прошедшие уходят из афиши сами (по дате). Задача: регулярно добавлять новые события с датой, местом, ценой и ссылкой на билеты.

## Источники (в таком порядке)
1. **tkt.ge** — билеты на концерты, театр, спорт, детские события: открывай разделы и страницы событий (WebFetch), берём дату, время, место, город, цену, ссылку на покупку.
2. **biletebi.ge** — то же.
3. **Telegram-канал https://t.me/s/events_ge** — анонсы событий (открывай через WebFetch веб-версию `t.me/s/…`; если не открывается — WebSearch «site:t.me events_ge»). Бери только посты с конкретной датой и местом.
4. Дополнительно, если мало событий в городе: сайты театров, филармоний, музеев, мэрий (batumi.ge, tbilisi.gov.ge), infobatumi.ge, фестивалей.
Сначала `node scripts/feed.mjs list --hours 96 --q концерт` и `--q афиша` (подборка сборщика, экономия).

## Что брать
- События на ближайшие **3 недели**, во всех городах (сначала Батуми и Тбилиси, потом Кутаиси и остальные).
- За запуск — 20–60 событий. Не дублируй: перед добавлением проверь, нет ли уже такой ссылки `source` в `data/events-import.json`.
- Только события с точной датой и местом. Без политики (митинги, партийные мероприятия), без 18+ с откровенным содержанием, без сомнительных «бесплатных инвестиционных семинаров».

## Поля события
- `title` — название по-русски (если событие на грузинском/английском — переведи понятно, имя артиста оставь как есть: «Концерт Nino Katamadze»);
- `city` — batumi, tbilisi, kutaisi, rustavi, kobuleti, zugdidi, poti, gori, telavi, borjomi;
- `kind` — concert | theatre | kids | festival | exhibition | party | games (мафия, квизы, настолки) | sport | talk | other;
- `starts_at` — дата и время начала с часовым поясом Тбилиси: `2026-11-14T19:00:00+04:00` (если время неизвестно — `T00:00:00+04:00`);
- `ends_at` — только для многодневных (выставка, фестиваль): `2026-12-01T23:59:00+04:00`; иначе не указывай;
- `venue` — площадка («Батумский драмтеатр»), `address` — адрес, если есть;
- `price` — как в источнике («20–60 ₾», «вход свободный»); нет данных — не указывай;
- `url` — прямая ссылка на покупку билета или страницу события;
- `image` — ссылка https на афишу/постер события из источника (организаторы публикуют их для продвижения), если есть;
- `description` — 2–4 предложения своими словами: что за событие, для кого, особенности (возраст 6+, язык спектакля). Без «лучший», «грандиозный», «не пропустите»;
- `source` — ссылка на страницу события или пост, откуда взято (уникальная для каждого события).

## Сохранение
1. Репозиторий ekaiv2025-a11y/nomerok (если нет — add_repo с access: push, клонировать), `git pull --rebase`.
2. Добавь в `data/events-import.json` в массив `batches` объект `{ "id": "<ГГГГ-ММ-ДД-ЧЧ>", "events": [ … ] }`. Удали пачки, у которых все события уже прошли.
3. `node scripts/check-events-import.mjs` — исправь ошибки.
4. Коммит `data/events-import.json`, пуш в main с повтором: `for i in 1 2 3 4; do git push -q origin main && break; git pull -q --rebase origin main; sleep $((2**i)); done`.
Сайт добавит события при ближайшей ежедневной проверке (около 11:00 по Тбилиси).
