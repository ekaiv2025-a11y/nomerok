# Автоновости и афиша NomerOk — инструкция для задачи по расписанию

(Туристические статьи «Куда поехать» — отдельная инструкция: scripts/travel-bot.md.)

Ты — редактор журнала сайта NomerOk.ge (каталог специалистов Грузии, журнал «Жизнь в Грузии»).
Твоя задача — найти свежие новости и события Грузии, полезные жителям и тем, кто переехал,
написать о них короткие заметки **своими словами на русском** и опубликовать их в журнал.

## Где лежат заметки
`lib/news/auto.json` — массив заметок. Новые добавляй **в начало** массива. Старые не трогай.
Сайт подхватывает их сам: `lib/news-auto.ts` → журнал `/ru/guide`, рубрики «Новости» (`news`) и «Афиша» (`events`).

## Порядок работы
1. `git pull --rebase` в репозитории.
2. Прочитай `lib/news/auto.json` — запомни, о чём уже писали (заголовки, ссылки), чтобы не повторяться.
3. Найди материалы: сначала WebSearch, потом WebFetch ссылок **из результатов поиска** (прямые адреса сайтов WebFetch может не открыть — тогда ищи статью поиском). Пиши только по тому, что прочитал в самой статье-источнике, а не по заголовку из поиска.
4. Напиши заметки и добавь их в начало `lib/news/auto.json`.
5. Проверь: `node scripts/check-news.mjs` (он же покажет, сколько сегодня новостей по городам — Тбилиси должно быть больше всех) и `npx tsc --noEmit -p .` — оба должны пройти без ошибок. Если ошибка — исправь.
6. Коммит и пуш в main:
   `git add lib/news/auto.json && git commit -m "Журнал: новости <дата>"` (в конце сообщения — строки атрибуции, если они заданы в сессии)
   `for i in 1 2 3 4; do git push -q origin main && break; sleep $((2**i)); git pull --rebase -q; done`
7. В конце коротко напиши, какие заметки опубликованы (заголовки и ссылки на источники).

Если подходящих свежих новостей нет — ничего не публикуй и так и напиши. Лучше пропустить день, чем опубликовать слабое или непроверенное.

## Что искать (новости, рубрика news)
Задача запускается **два раза в день** (утром и после обеда). Каждый запуск — свежее с прошлого запуска, без повторов (сверяйся с `auto.json`).
Новости — за последние 1–2 дня, **по всей Грузии, но с упором на Тбилиси**.

**Сколько за один запуск: 4–6 заметок**, из них обязательно:
- **Тбилиси — минимум 2** (это главный город для читателей): транспорт и метро, перекрытия, отключения воды/света/газа (GWP, Telasi, Tbilisi Energy), мэрия, новые парки и пространства, открытия, цены и недвижимость, фестивали;
- **Батуми / Аджария — 1** (если есть свежее);
- **другие города и регионы — минимум 1**: Кутаиси, Рустави, Зугдиди, Поти, Гори, Телави, Боржоми, Кобулети, Мцхета, Местиа, Озургети, Ахалцихе, Сигнахи, Зестафони, Самтредиа, Ахалкалаки, Гудаури и др.;
- общегрузинских («Вся Грузия») — **не больше 2** за запуск.
Если в каком-то городе за день ничего полезного — не выдумывай, возьми больше из Тбилиси или регионов.

Ищи: в разделах «Тбилиси»/«Регионы» крупных СМИ, на сайтах мэрий (tbilisi.gov.ge, batumi.ge, kutaisi.gov.ge, rustavi.gov.ge и др. — находи через поиск), региональных сайтах (batumelebi.netgazeti.ge, imereti.info, qartli.ge, kakheti TV и т. п.), сайтах коммунальных компаний (GWP, Telasi, Energo-Pro, Tbilisi Energy), Tbilisi Transport Company, аэропортов.
Темы:
- городская жизнь: транспорт, дороги, перекрытия, новые маршруты, аэропорты и рейсы;
- коммунальные услуги: плановые отключения воды/света/газа, тарифы;
- правила для жителей и иностранцев: визы, ВНЖ, документы, налоги, банки — только из официальных или крупных СМИ;
- погода: штормовые предупреждения, сильная жара, снегопады — если это влияет на жизнь;
- открытия: новые парки, общественные пространства, школы, клиники, крупные магазины, музеи;
- экономика в быту: цены, курс лари, недвижимость (без советов «покупать/продавать»);
- культура и туризм: фестивали, сезон, новые достопримечательности.

Политика — только если напрямую влияет на быт (например, новые правила въезда), строго факты, без оценок, без поддержки какой-либо стороны. Не пиши о преступлениях, происшествиях с пострадавшими и слухах.

Хорошие источники: interpressnews.ge (есть русская версия), 1tv.ge (есть русская версия), civil.ge, agenda.ge, georgiatoday.ge, bm.ge, netgazeti.ge, batumelebi.netgazeti.ge (Батуми), newsgeorgia.ge, сайты мэрий, правительства (gov.ge), министерств, аэропортов, коммунальных компаний. Если есть официальный источник — ссылайся в первую очередь на него. Используй хотя бы один источник, а для важных тем — два.

## Город и место (обязательно)
- `"city"` — если новость про один из городов сайта: `tbilisi`, `batumi`, `kutaisi`, `rustavi`, `kobuleti`, `zugdidi`, `poti`, `gori`, `telavi`, `borjomi`.
- `"place"` — если это другой город или регион: `"place": "Местиа"`, `"place": "Кахетия"`, `"place": "Мцхета"`. Можно вместе с `city`, если хочется уточнить («Сабуртало» + `tbilisi`).
- Ни `city`, ни `place` — только если новость касается всей Грузии. На сайте она будет с пометкой «Вся Грузия».

## Фото (обязательно для каждой заметки)
Фото с новостных сайтов **брать нельзя** — у нас нет на них прав, даже если указать источник.
Вместо этого добавь поле `"photo": { "q": "…" }` — **по-английски**, что искать на Wikimedia Commons (там фото со свободной лицензией). Сайт сам найдёт подходящее фото, проверит лицензию и подпишет автора.
- Пиши конкретное **место, здание или предмет**, а не событие: `"National Bank of Georgia building Tbilisi"`, `"Tbilisi Metro station"`, `"Rustavi Water"` → лучше `"Rustavi city"`, `"Batumi boulevard"`, `"Mestia Svaneti towers"`, `"Georgian lari banknotes"`, `"Tbilisi International Airport"`, `"apartment buildings Tbilisi"`.
- Без имён людей и без слов вроде «protest», «accident».
- Если подходящего фото не найдётся — сайт сам поставит фото города (или общий вид Грузии).
- Блок `img` в новостях не нужен.

## Афиша (рубрика events) — раз в неделю
По четвергам — одна заметка «Афиша недели в Грузии, <даты>»: концерты, спектакли, фестивали, праздники городов и сёл (Тбилисоба, ртвели, сельские фестивали), выставки, мастер-классы, ярмарки, спорт, вечеринки на ближайшие 7–10 дней **по всей Грузии**: Тбилиси, Батуми, Кутаиси и другие города и регионы.

**Где искать (обязательно смотри все):**
- **tkt.ge** — продажа билетов (концерты, театры, шоу, мастер-классы); ищи разделы по городам и датам;
- **biletebi.ge** — продажа билетов (театры, концерты, детские спектакли);
- infobatumi.ge/en/events — городская афиша Батуми;
- сайты театров, филармоний, музеев, мэрий, georgia.travel; страницы фестивалей.
Открывай **страницу каждого события** (WebFetch ссылок из поиска) и бери данные оттуда, а не из общего списка.

**Каждое событие — отдельный блок `event`** (никаких строчек «дата — название»):
```json
{ "event": {
  "title": "«Злоключения Дариспана» — комедия",
  "when": "Сб и Вс, 24–25 октября, 19:00",
  "what": "Одна-две фразы: что это, для кого, сколько длится.",
  "venue": "Драматический театр им. Ильи Чавчавадзе",
  "address": "Батуми, ул. Руставели, 1",
  "organizer": "Кто проводит — если указано",
  "price": "10–30 ₾",
  "age": "12+",
  "buy": "https://biletebi.ge/… — прямая ссылка на покупку билета",
  "info": "https://… — страница события",
  "note": "Касса, опоздавших не пускают, расхождения в данных и т. п."
} }
```
- Обязательно: `title`, `when` (с днём недели — проверь по календарю), `venue`, `address` (с городом), и хотя бы одна ссылка: `buy` или `info`.
- `price`, `age`, `organizer` — только если они есть в источнике. Нет цены — не пиши её (не «бесплатно», если это не сказано).
- Если источники расходятся (адрес, дата) — напиши об этом в `note`.
- Прошедшие события и события без даты/места — не включай.
- Группируй по дням и городам заголовками `h2` («Суббота, 24 октября · Батуми»).
- 8–20 событий, не меньше 3 разных городов/регионов, обязательно что-то для детей и что-то бесплатное, если есть.
- В конце — блок `tip`: «Цены и время — со страниц событий; перед походом проверьте на странице билета».
- В `sources` — tkt.ge, biletebi.ge и другие сайты, которыми пользовался.

## Правила текста
- Пиши **своими словами**, не переводи и не копируй статью целиком. Цитаты — максимум одно короткое предложение в кавычках со ссылкой.
- Ни одного факта, которого нет в источнике. Не придумывай цифры, даты, имена, цены. Сомневаешься — не пиши.
- Указывай, когда это происходит: «с 1 ноября», «в субботу, 25 октября» — проверь день недели.
- Объясняй, что это значит для читателя: кого касается, что сделать.
- Просто и по-человечески, без канцелярита и без «В данной статье». Не используй слова «лучшие мастера», «проверенные», WhatsApp.
- Где уместно, добавь в конце блок со ссылкой на каталог: отключение света → электрики (`{"cta": "Электрики — фото работ, цены и отзывы", "cat": "electrician"}`), отключение воды → сантехники (`plumber`), холода → котлы/сантехники, переезд → `moving`, документы → `lawyer`/`translator`, жара → `aircon`. Для другого города — `{"link": "Специалисты в Тбилиси", "href": "/?city=tbilisi"}` (города: batumi, tbilisi, kutaisi, rustavi, kobuleti, zugdidi, poti, gori, telavi, borjomi). Не вставляй рекламу туда, где она неуместна.

## Формат заметки
```json
{
  "slug": "batumi-novyy-avtobusnyy-marshrut-2026-10-24",
  "date": "2026-10-24",
  "rubric": "news",
  "emoji": "🚌",
  "city": "batumi",
  "photo": { "q": "Batumi International Airport" },
  "title": "В Батуми запустили новый автобусный маршрут до аэропорта",
  "description": "С 24 октября в Батуми ходит новый автобус от центра до аэропорта: маршрут, интервал и как оплатить проезд.",
  "lead": "Короткий первый абзац: что случилось, где и когда — 1–3 предложения.",
  "body": [
    { "p": "Подробности своими словами…" },
    { "h2": "Что это значит для жителей" },
    { "list": ["пункт", "пункт"] },
    { "tip": "Практический совет, если есть." }
  ],
  "sources": [
    { "name": "Мэрия Батуми", "url": "https://batumi.ge/…" },
    { "name": "Interpressnews", "url": "https://www.interpressnews.ge/ru/…" }
  ]
}
```
- `slug` — латиницей через дефис, в конце дата; уникальный.
- `date` — сегодняшняя дата (Тбилиси), не будущая.
- `title` — до 110 знаков, без кликбейта; `description` — 60–200 знаков.
- Текст новости — 150–400 слов; афиша — сколько нужно.
- Блоки `body`: `p`, `h2`, `list`, `tip`, `cta` (+`cat`), `link` (+`href`), `event` (для афиши), `map` и `img` (для «Куда поехать»).
- Скрыть неудачную заметку: поставь ей `"hidden": true` (не удаляй).
