# Нотариусы Грузии — инструкция для задачи по расписанию

## Зачем
Решение владельца (07.11.2026): каталог наполняем сами по открытым данным. Нотариальная палата Грузии публикует реестр всех нотариусов с адресом бюро, рабочими телефонами и часами работы. Делаем анкету каждого нотариуса в категории «Нотариус». Контакт — рабочий телефон бюро из реестра.

## Источник
Реестр: `https://notary.ge/eng-3718-notary-bureaus-page-1` … `-page-29` (≈10 нотариусов на странице, по алфавиту, вся Грузия).
Открывай через WebFetch. Ссылки на следующие страницы бери из блока пагинации ответа (WebFetch открывает только ссылки, которые уже появлялись). Если адрес страницы не открывается — попробуй тот же с `www.`, затем найди через WebSearch «notary.ge eng-3718-notary-bureaus-page-N».
В запросе к WebFetch проси вернуть **всех нотариусов страницы дословно**: имя, адрес, все телефоны, часы работы, пометки (Mediator Notary, works on holidays, adapted for persons with disabilities), ник вида `xxx_notary`, и ссылки пагинации.

## Порядок за запуск
1. Репозиторий ekaiv2025-a11y/nomerok (если нет — add_repo с access: push, клонировать), `git pull --rebase`.
2. Посмотри «Прогресс» внизу — с какой страницы продолжить. За запуск — до 15 страниц.
3. Для каждого нотариуса из городов: Батуми (batumi), Тбилиси (tbilisi), Кутаиси (kutaisi), Рустави (rustavi), Кобулети (kobuleti), Зугдиди (zugdidi), Поти (poti), Гори (gori), Телави (telavi), Боржоми (borjomi) — добавь запись. **Нотариусов из других городов и сёл пропускай** (у нас нет таких городов). Сёла рядом с Тбилиси (Цхнети, Кахрети и т. п.), если в реестре они в регионе Тбилиси, — tbilisi.
4. Поля записи:
   - `name` — имя и фамилия по-русски, кириллицей, как принято передавать грузинские имена: «Zaal Zakarashvili» → «Заал Закарашвили», «Ana» → «Ана», «Davit» → «Давит», «Giorgi» → «Георгий», «Ketevan» → «Кетеван», «Nino» → «Нино», «Tamar» → «Тамар», «Irakli» → «Ираклий», «Aleksandre» → «Александре»;
   - `category` — `notary`;
   - `title` — «Нотариус» (если в реестре Mediator Notary — «Нотариус, медиатор»);
   - `services` — ровно так: «Удостоверение сделок и договоров\nДоверенности\nЗаверение копий документов и подписей\nКонсультация по нотариальным действиям»;
   - `about` — 1–2 предложения по фактам из реестра: «Нотариальное бюро в районе Сабуртало (Тбилиси).» + если есть: «Работает в праздничные дни.», «Офис приспособлен для людей с инвалидностью.». Ничего не выдумывай;
   - `phones` — все телефоны из реестра в формате `+995 5XX XXX XXX` / `+995 32 2XX XX XX`;
   - `address_ru` — адрес по-русски: «Тбилиси, Сабуртало, пр. Казбеги, 12б». Улицы — по-русски («Vazha-Pshavela Avenue» → «пр. Важа-Пшавела»), «N23» → «23»;
   - `city` — id города из списка выше;
   - `hours` — по-русски: «Пн–Пт 10:00–18:00, перерыв 13:00–14:00; Сб 10:00–15:00»;
   - `source_url` — адрес страницы реестра + `#` + ник (`#achalauri_notary`) или имя латиницей, если ника нет (`#zaal-zakarashvili`). Должен быть уникальным.
   Устаревшие пометки о замене нотариуса (replacement … 2017) не переноси.
5. Добавь в `data/registry-import.json` в `batches` объект `{ "id": "notary-<ГГГГ-ММ-ДД>-p<первая>-<последняя>", "source": "Реестр Нотариальной палаты Грузии, notary.ge", "items": [ … ] }`.
6. `node scripts/check-registry-import.mjs` — исправь ошибки.
7. Обнови «Прогресс» ниже, коммит `data/registry-import.json` и `scripts/notary-bot.md`, пуш в main с повтором:
   `for i in 1 2 3 4; do git push -q origin main && break; git pull -q --rebase origin main; sleep $((2**i)); done`
Сайт создаст анкеты при ближайшей ежедневной проверке (около 11:00 по Тбилиси), до 150 за раз.

## Когда все страницы пройдены
Напиши в итоге «Реестр пройден полностью» — задачу можно выключить.

## Нельзя
- Почту, Telegram, ники в тексте анкеты; отзывы, рейтинги, цены.
- Выдумывать языки, опыт, услуги сверх списка выше.
