# Nomerok.ge — каталог специалистов Батуми

Рабочий сайт: настоящие специалисты (мастера, репетиторы, врачи и другие), заявки сохраняются в базу, уведомления приходят в Telegram, есть админка.

## Что умеет сайт

**Для посетителей**
- Каталог специалистов с поиском и 26 категориями: от сантехников до врачей и юристов. Показываются только те, кого вы опубликовали.
- Страница каждого специалиста со своей ссылкой (`ваш-домен/master/...`). При отправке в Telegram или WhatsApp видно имя и услуги специалиста.
- Кнопка «Показать контакты»: телефон, WhatsApp, Telegram. Телефона нет в коде страницы, поэтому роботы не соберут номера.
- Форма «Оставить заявку»: общая или конкретному специалисту.
- Форма «Я специалист»: анкета с согласием на публикацию.

**Для вас (админка по адресу `/admin`)**
- Заявки клиентов: телефон, кнопка WhatsApp, статусы «Новая / В работе / Готово / Спам».
- Анкеты специалистов: кнопки «Опубликовать» и «Отклонить».
- Список специалистов: редактирование, скрытие, удаление, ручное добавление (например, из чатов, если человек согласен).
- Счётчик «Открытий»: сколько разных людей открыли контакты специалиста в этом месяце. Пригодится для оплаты «10 заказов = 50₾».
- Каждая новая заявка и анкета сразу приходит вам в Telegram.

**Честность:** нет выдуманных рейтингов, отзывов и «чатов». Пока каталог пуст, сайт предлагает оставить заявку.

## Как запустить: 5 шагов, около 30 минут

Несколько слов, которые встретятся дальше:
- **База данных (Supabase)** — место, где хранятся специалисты и заявки. Похоже на таблицу Excel в интернете.
- **Переменные окружения** — секретные настройки сайта: ключи и пароли. Их вписывают в Vercel, а не в код.
- **Деплой** — выкладка сайта в интернет.

### Шаг 1. База данных Supabase

1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** → войдите через GitHub.
2. **New project**. Имя: `nomerok`. Придумайте пароль базы и сохраните его. Регион: **Central EU (Frankfurt)**, он ближе всего к Грузии.
3. Подождите пару минут, пока проект создаётся.
4. Слева откройте **SQL Editor** → **New query**.
5. Откройте файл `supabase/migrations/0001_init.sql` из этой папки, скопируйте весь текст, вставьте и нажмите **Run**. Должно появиться «Success».
6. Слева **Project Settings** (шестерёнка) → **API**. Скопируйте в блокнот:
   - **Project URL**: это `SUPABASE_URL`;
   - ключ **service_role** (нажмите «Reveal»): это `SUPABASE_SERVICE_ROLE_KEY`.
   ⚠️ Ключ service_role секретный. Никому его не отправляйте и не публикуйте.

### Шаг 2. Telegram-бот для уведомлений

1. В Telegram откройте **@BotFather** → отправьте `/newbot`.
2. Имя: `Nomerok`. Ник должен заканчиваться на `bot`, например `NomerokGeBot`.
3. BotFather пришлёт токен вида `123456:ABC...`. Это `TELEGRAM_BOT_TOKEN`.
4. Найдите своего бота в Telegram и отправьте ему любое сообщение, например «привет».
5. Откройте в браузере адрес, подставив свой токен:
   `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
   Найдите на странице `"chat":{"id":123456789`. Это число — `TELEGRAM_ADMIN_CHAT_ID`.

### Шаг 3. Загрузить код на GitHub

1. На [github.com](https://github.com) нажмите **+** → **New repository**. Имя: `nomerok`, выберите **Private** → **Create repository**.
2. На странице репозитория нажмите ссылку **uploading an existing file**.
3. Перетащите в окно **всё содержимое** этой папки (файлы и папки `app`, `components`, `lib`, `supabase` и остальные) → **Commit changes**.

### Шаг 4. Выложить сайт на Vercel

1. Зайдите на [vercel.com](https://vercel.com) → войдите через GitHub → **Add New… → Project** → выберите `nomerok` → **Import**.
2. Раскройте **Environment Variables** и добавьте по одной строке:

   | Name | Value |
   |---|---|
   | `SUPABASE_URL` | из шага 1 |
   | `SUPABASE_SERVICE_ROLE_KEY` | из шага 1 |
   | `ADMIN_PASSWORD` | придумайте пароль для админки, от 12 символов |
   | `TELEGRAM_BOT_TOKEN` | из шага 2 |
   | `TELEGRAM_ADMIN_CHAT_ID` | из шага 2 |
   | `NEXT_PUBLIC_SITE_NAME` | `Nomerok` (название сайта; поменяете здесь — поменяется везде) |
   | `NEXT_PUBLIC_SITE_URL` | ваш домен, например `https://nomerok.ge` (пока домена нет — адрес от Vercel, например `https://nomerok.vercel.app`) |
   | `NEXT_PUBLIC_SUPPORT_TELEGRAM` | ваш ник в Telegram без @ (необязательно) |

3. **Deploy**. Через 1–2 минуты сайт будет доступен по адресу вида `nomerok.vercel.app`.
4. Проверьте: отправьте тестовую заявку. Она должна прийти вам в Telegram и появиться в `/admin`.

> Если переменные поменялись позже: Vercel → проект → **Settings → Environment Variables** → измените → **Deployments** → у последнего нажмите **⋯ → Redeploy**.

### Шаг 5. Подключить домен nomerok.ge

Домен куплен на ge.domains. Подключаем его к Vercel через «NS-серверы». NS-серверы — это адрес, который говорит интернету, кто управляет доменом. Мы передаём управление в Vercel, дальше он всё настроит сам.

1. Vercel → проект → **Settings → Domains** → введите `nomerok.ge` → **Add**. Потом добавьте так же `www.nomerok.ge`.
2. Vercel покажет подсказку. Выберите вариант **Nameservers** / **Vercel DNS**. Он покажет два адреса, обычно `ns1.vercel-dns.com` и `ns2.vercel-dns.com`.
3. На ge.domains → **Мои домены** → у nomerok.ge нажмите **«Управление НС»** → удалите старые адреса → впишите два адреса из Vercel → сохраните.
4. Подождите от 15 минут до суток. Когда в Vercel у домена появится зелёная галочка, сайт откроется по `https://nomerok.ge`. Защищённое соединение (https) включится само.
5. Впишите `https://nomerok.ge` в `NEXT_PUBLIC_SITE_URL` и сделайте Redeploy.

## Как пользоваться админкой

Адрес: `ваш-сайт/admin`, пароль: `ADMIN_PASSWORD`.

- **Пришла анкета** → вкладка «Анкеты» → «Редактировать»: поправьте текст, если нужно → «Опубликовать». Специалист сразу появится на сайте.
- **Специалист из чата** → «+ Добавить специалиста». Отметьте «Специалист дал согласие» и «Сразу опубликовать». Публикуйте только с согласия человека. У врачей, психологов и юристов заполняйте «Образование и документы».
- **Пришла заявка** → позвоните или напишите клиенту, передайте заявку специалисту и поставьте статус «В работе», затем «Готово».
- **Фото специалиста**: загрузите картинку в Supabase → **Storage** (создайте публичный bucket `photos`), скопируйте ссылку и вставьте её в поле «Ссылка на фото».

## Запуск на своём компьютере (необязательно)

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

```
npm install
npm run dev
```

Откройте http://localhost:3000. Пока нет файла `.env.local` с ключами Supabase, сайт хранит данные во временном файле `.data/db.json`: так можно всё проверить без базы. Для входа в админку создайте файл `.env.local` со строкой `ADMIN_PASSWORD=ваш_пароль`.

## Что внутри (для программиста)

- Next.js 16 (App Router), React 19, Tailwind CSS 4, Supabase, zod.
- Весь доступ к базе идёт только с сервера (`lib/db.ts`) через ключ service_role. RLS включён без политик, поэтому из браузера к таблицам доступа нет.
- `app/api/*` — приём форм (с защитой от спама: скрытое поле, проверка времени заполнения, ограничение частоты) и выдача контактов.
- `app/admin/*` — админка на server actions. Вход по паролю, в cookie хранится HMAC-подпись.
- `supabase/migrations/0001_init.sql` — схема таблиц `masters`, `requests`, `contact_views`.
